# Design Stargazer Around Vetting, Not Discovery

As of November 2026, Stargazer's design should rest on one finding above all others: finding odd things in public sky data is cheap, and deciding whether any of them are real is where all the work lies. Every large search on record has turned millions to billions of raw detections into zero confirmed artificial signals. SETI@home went from about 12 billion detections to a few hundred candidates, Breakthrough Listen's Proxima search from 4.2 million hits to one interference signal, and the optical quasar surveys from hundreds of "periodic" candidates to essentially none that hold up. The public data a tool can reach are mostly reduced products: radio hit tables and spectrogram files, cloud-hosted light-curve catalogues, archive query services that use the Virtual Observatory's table-query protocol (TAP), and alert streams. Raw radio voltages from the newest SETI programmes are available only on request. No quasar is known to "pulse". Quasar variability is red noise, and the few periodicities that survive come from natural jet or binary sources. Pulsars, fast radio bursts (FRBs) and the new long-period radio transients already produce, by natural means, nearly every pattern a naive message detector would flag. Methods for recovering structure from an unknown bitstream are mature: framing, layout, coding and grammar can be found without a key. Assigning meaning without a key has never worked, except where the message itself supplies anchors such as numbers, physics or pictures. The tool should therefore be built as a calibrated, provenance-tracking anomaly and structure engine. Each detector should have an empirical null model, injection–recovery tests and trials accounting. Candidates should pass through a tiered vocabulary that never says "technosignature". The design also has to absorb several near-term shocks: Gaia's fourth data release (DR4) on 2 December 2026, a cyber-security outage at the Strasbourg astronomical data centre (CDS), confirmed Zwicky Transient Facility (ZTF) funding that ends in December 2026, Breakthrough Listen's expiring ten-year commitment, and GPL licences on several key libraries.

*How to read the evidence tags.* Each load-bearing claim carries a tag: **[read]** means it was checked in the primary source (a paper, documentation page, package metadata, live API response, or a test run during the research); **[search]** means it comes from a web-search summary only; **[recalled]** means it is background knowledge that was not re-checked. The research ran with restricted network access, so some hosts could not be opened. These included GitHub, the CDS services, several Berkeley data hosts and most journal sites, which is why some claims rest on search summaries.

## Public data reaches software through four doors, and raw radio is mostly behind a closed one

### Radio SETI archives are large, old and only partly machine-accessible

The Breakthrough Listen (BL) Open Data Archive is the only large public radio-SETI archive. Paging through its search front end on 21 November 2026 counted about **859,000 catalogued files** from the Green Bank Telescope (GBT), Parkes and the Automated Planet Finder (APF) **[read]** ([BI Open Data Archive](https://breakthroughinitiatives.org/opendatasearch)). The only working machine interface is a plain HTTP GET form that returns HTML tables. Each row carries an MD5 checksum and a download URL, and many of those URLs point to plain-HTTP Berkeley hosts. A "beta" JSON API exists in source code, but it now redirects to plain HTTP and could not be tested **[read]** ([seti.berkeley.edu/opendata](https://seti.berkeley.edu/opendata)). The index also appears frozen. The newest GBT entries date from November 2022 and the newest Parkes entries from May 2021, although BL's own 2026 review reports **31.4 PB** of data held across its systems **[read]** ([MacMahon 2026](https://arxiv.org/abs/2610.07482)). Typical file sizes are the real constraint. A 5-minute high-spectral-resolution L-band file is about 15 GB, so one six-scan ON/OFF cadence is about 90 GB. A per-compute-node product of 1–3 GB is the natural download unit **[read]** ([BI Open Data Archive](https://breakthroughinitiatives.org/opendatasearch)). The newer commensal programmes publish software and papers but share data only on request: BLUSE at MeerKAT, COSMIC at the VLA and the Allen Telescope Array (ATA) survey **[read]** ([Czech et al. 2026](https://arxiv.org/abs/2607.23651); [Tremblay et al. 2025](https://arxiv.org/abs/2501.17997); [Gerrard et al. 2026](https://arxiv.org/abs/2610.07065)). FAST releases follow a 12-month proprietary period, and whether they include SETI data is unconfirmed **[search]** ([FAST Data Release 25](https://lssf.cas.cn/en/facilities/sa/fast/notice/202605/t20260502_5108627.html)).

The practical consequence is that Stargazer's cheapest radio input is published hit and event tables, not spectra. The Enriquez et al. 2017 tables of about 29 million hits are CC BY 4.0. The Price et al. 2020 event CSVs, with matching turboSETI outputs on Zenodo, are also CC BY 4.0. UCLA's candidate-detection tables on Zenodo are CC0 **[read]** ([lband2017 downloads](https://seti.berkeley.edu/lband2017/downloads.html); [Zenodo 7600403](https://zenodo.org/records/7600403); [Zenodo 4023234](https://zenodo.org/records/4023234)). These tables allow cross-survey meta-analysis, such as frequency and drift clustering or recurrence at one sky position, without downloading any spectra.

### Optical, infrared and high-energy archives are now cloud-first

The non-radio archives have changed more than the radio ones. NASA's archives (MAST, IRSA and HEASARC) now place anonymous, no-cost copies of their main time-domain sets in AWS object storage, many as HATS-partitioned Parquet (sky-tiled columnar files) readable with the LSDB library. The copies include TESS, Kepler and K2, Pan-STARRS1 DR2 (72.3 billion detections), Gaia DR3, ZTF DR24 light curves (8.4 TB), NEOWISE single exposures (42 TB), SPHEREx and HEASARC's mission archives **[read]** ([stpubdata listing](https://stpubdata.s3.amazonaws.com/?list-type=2&delimiter=/); [ZTF HATS README](https://ipac-irsa-ztf.s3.amazonaws.com/ztf/enhanced/dr24/lc/hats/README.txt); [NASA HEASARC registry entry](https://raw.githubusercontent.com/awslabs/open-data-registry/main/datasets/nasa-heasarc.yaml)). IRSA itself now tells users who need **more than about 1,000 ZTF light curves** to use the HATS copy instead of its light-curve API **[read]** ([IRSA ZTF Lightcurve API](https://irsa.ipac.caltech.edu/docs/program_interface/ztf_lightcurve_api.html)). For bulk work, the right pattern is to discover objects through the archive APIs and then read Parquet in place, ideally on a free hosted platform in the same cloud region.

Live tests on 21 November worked for the MAST Portal API, IRSA TAP, ESA's Gaia TAP and HEASARC TAP. HEASARC's TAP service exposes **1,034 tables** and returns only binary VOTable, rejecting CSV requests **[read]** ([HEASARC in the VO](https://heasarc.gsfc.nasa.gov/docs/archive/vo/)). The Fermi-LAT Light Curve Repository is the only uniformly processed, 18-year, regularly sampled public AGN light-curve set. It covers 1,525 variable sources at 3-day, weekly and monthly cadence and is served through an undocumented but working JSON endpoint **[read]** ([LCR about](https://fermi.gsfc.nasa.gov/ssc/data/access/lat/LightCurveRepository/about.html)).

Two access facts change the plan for the coming weeks. **Gaia DR4 is scheduled for 2 December 2026**. It is about 400 TB, with 121.8 billion epoch-photometry rows plus epoch astrometry and epoch spectra, and it ships tables designed to veto scan-law artefacts (`spurious_signal`, `commanded_scan_law`, `gaia_gap`) **[read]** ([Gaia DR4 content](https://www.cosmos.esa.int/web/gaia/dr4)). The ESA archive is offline from 25 November to 2 December. Since 14 October it has capped anonymous users at 50 sources per DataLink call, against 5,000 for free registered accounts. Per-source time series are available only through DataLink, not TAP **[read]** ([Gaia archive quotas](https://www.cosmos.esa.int/web/gaia-users/archive/collaborate#GaiaArchiveUserQuotas); [Gaia news](https://www.cosmos.esa.int/web/gaia/news)). Separately, the CDS services in Strasbourg (SIMBAD, VizieR and X-Match) have been degraded by a cyber-security incident since at least 9 November. Both test queries failed, so name resolution and cross-matching need mirror fallback, and the archives' own TAP services should be the default **[read]** ([VizieR notice](https://vizier.cds.unistra.fr/)).

### Pulsar and FRB catalogues are small and scriptable; long-period transients have no catalogue

The pulsar and FRB "catalogue spine" is megabyte-scale and can be cached. Its pieces are the ATNF pulsar catalogue (version 2.8.1, June 2026, 4,393 pulsars) through the unofficial `psrqpy` package, the RRATalog list of 335 rotating radio transients, the second CHIME/FRB catalogue (4,539 bursts from 3,641 sources, including 83 repeaters) and the Transient Name Server, which requires a registered bot key **[search]** for the catalogue facts and **[read]** for psrqpy's behaviour ([ATNF history](https://www.atnf.csiro.au/research/pulsar/psrcat/catalogueHistory.html); [psrqpy](https://pypi.org/project/psrqpy/); [RRATalog](https://rratalog.github.io/rratalog); [CHIME/FRB Catalog 2](https://arxiv.org/abs/2601.09399)). Pulsar-timing-array releases are the cleanest small time series. NANOGrav's 15-year set is about 0.6 GB and EPTA DR2 about 39 MB, both readable with PINT **[search]** ([Zenodo 16051178](https://zenodo.org/records/16051178); [Zenodo 8300645](https://zenodo.org/records/8300645)). Long-period radio transients, of which there are now roughly 12–15, have **no machine-readable catalogue**. They are also found in images rather than high-time-resolution data, so a filterbank-only tool would miss the whole class **[search]** ([Rea, Hurley-Walker & Caleb 2026](https://arxiv.org/abs/2601.10393)).

### Alert brokers are the only public window on Rubin

The Rubin Observatory began its ten-year survey (LSST) on 29 June 2026, then lost 3.5 months to a weather outage (15 July to 27 October). Its alerts have been world-public through seven full-stream brokers since 24 February 2026. Its catalogues and images are restricted to data-rights holders, and the first full data release is now expected between July and November 2028 **[read]** ([RTN-011 parameters](https://raw.githubusercontent.com/lsst/rtn-011/main/data/parameters.yaml)). Each broker needs its own credential and has its own limits. Lasair allows 100 calls per hour on a user token **[read]** ([Lasair REST API docs](https://raw.githubusercontent.com/lsst-uk/lasair-lsst/main/docs/source/core_functions/rest-api.md)). ANTARES clients older than 2.0 stopped working on 4 November 2026 **[read]** ([antares-client](https://pypi.org/project/antares-client/)). Brokers are therefore an enrichment and streaming source, not a harvesting one.

## Nature already makes every "pulse" a naive detector would flag

### Quasars do not pulse, and their periodicity claims have mostly collapsed

Quasar variability is aperiodic red noise in every band. In the optical it is approximated by a damped random walk (DRW) with rest-frame damping times of hundreds of days, and it departs from that model in documented ways, which a damped harmonic oscillator, or DHO (a CARMA(2,1) model), often fits better **[search]** ([MacLeod et al. 2010](https://arxiv.org/abs/1004.0276); [Yu et al. 2025](https://arxiv.org/abs/2508.12076)). Red noise puts its power at the lowest frequencies a light curve can sample. A few cycles of apparent sinusoid are therefore the expected output of pure noise, and the standard Lomb–Scargle false-alarm formulas, which assume white noise, do not apply **[search]** ([Vaughan et al. 2016](https://arxiv.org/abs/1606.02620)).

The survey record bears this out. Pan-STARRS Medium Deep candidates fell from 26 to 1 when baselines were extended. PTF's 33 candidates showed no significant periodicity under a 2024 re-assessment with null-signal templates. In all 116 testable Gaia DR3 candidates, out of 181, the periodic model failed to predict later ZTF data. The CRTS candidates, taken as real binaries, would over-predict the nanohertz gravitational-wave background **[search]** ([Liu et al. 2019](https://arxiv.org/abs/1906.08315); [Robnik et al. 2024](https://arxiv.org/abs/2407.17565); [arXiv:2509.10601](https://arxiv.org/abs/2509.10601); [Sesana et al. 2018](https://arxiv.org/abs/1703.10611)). NANOGrav's targeted search of 114 candidate binary AGN found no continuous-wave signal **[search]** ([NANOGrav 2025](https://arxiv.org/abs/2508.16534)).

The claims that survive are beamed jet sources with many coherent cycles. PKS 2131−021 shows a 47.9-year coherent radio sinusoid, rejected as red noise at p ≈ 2×10⁻⁷. PG 1553+113 shows a gamma-ray cycle of about 2.2 years tracked for 17 years. Both have natural binary or jet-precession explanations **[search]** ([Kiehlmann et al. 2024](https://arxiv.org/abs/2407.09647); [arXiv:2603.04527](https://arxiv.org/abs/2603.04527)). Completeness is also poor. A periodogram recovers only about 23–45% of injected sinusoids, and about 1–9% of sawtooth shapes, under DRW noise **[search]** ([Lin, Charisi & Haiman 2026](https://arxiv.org/abs/2505.14778)).

The closest real "pulsing" in galactic nuclei comes from X-ray quasi-periodic eruptions (about a dozen sources, recurring every 2.4 hours to about 4.5 days), a few drifting X-ray quasi-periodic oscillations (QPOs), and repeating flares such as ASASSN-14ko's 114-day cycle. None of these is clock-like, and their periods drift in both directions **[search]** ([QPE review 2026](https://arxiv.org/abs/2607.15359); [Chakraborty et al. 2026](https://arxiv.org/abs/2602.16776); [Payne et al. 2021](https://arxiv.org/abs/2009.03321)).

The one historical "pulsing quasar beacon" is a warning, not a lead. In 1965, CTA-102's radio variability was announced as a possible artificial signal, and the claim collapsed once quasar variability was understood **[search]** ([SETI in Russia/USSR](https://arxiv.org/abs/1905.03225)). No peer-reviewed proposal for artificially modulated quasar light was found. The energetics explain why: a 10% modulation of a quasar means controlling 10⁴⁴–10⁴⁶ erg s⁻¹. Quasar redshift periodicity is a fringe claim explained by selection effects **[search]** ([Redshift quantization](https://en.wikipedia.org/wiki/Redshift_quantization)).

### Pulsars, FRBs and long-period transients supply the rest of the false patterns

Natural pulsar emission produces many message-like patterns. Pulsars null (switch off), and their null sequences fail randomness tests. They switch between discrete profile modes, show drifting sub-pulses, emit power-law giant pulses, glitch, and scintillate **[recalled]** ([Redman & Rankin 2009](https://ui.adsabs.harvard.edu/abs/2009MNRAS.395.1529R); [Lyne et al. 2010](https://arxiv.org/abs/1006.5184)). FRB repeaters show bimodal waiting times and aftershock-like clustering, so a Poisson null is wrong for them too **[search]** ([arXiv:2409.13247](https://arxiv.org/pdf/2409.13247)). In practice "not random" is never evidence of artifice. The null hypothesis has to be a physically motivated surrogate, such as a two-state Markov model of nulling or a Weibull or aftershock burst process.

Periodicity in FRBs is real but natural and fragile. FRB 20180916B has a 16.35-day activity window. FRB 20121102A's period of about 157–160 days lost robustness once FAST non-detections were included. One CHIME burst, FRB 20191221A, shows 216.8 ms sub-structure at 6.5σ, which its authors read as a neutron-star signature **[search]** ([arXiv:2310.16307](https://arxiv.org/html/2310.16307v2); [arXiv:2507.15790](https://arxiv.org/pdf/2507.15790); [arXiv:2107.08463](https://arxiv.org/abs/2107.08463v2)).

Long-period radio transients have periods from 7 minutes to 6.5 hours. A growing subset are white-dwarf binaries, including ASKAP J1745−5051, the first shown to be accreting (June 2026), and GPM J0715−1141 with a Sun-like companion (12 November 2026). Their emission mechanism remains unexplained, and in 2026 that means several natural models compete, not that none exists **[search]** ([arXiv:2601.10393](https://arxiv.org/abs/2601.10393); [Nature Astronomy 2026](https://www.nature.com/articles/s41550-026-03016-z)).

No pulsar, FRB or long-period transient has credible evidence of artificial origin. The published searches that targeted pulsed or periodic artificial signals returned quantitative nulls. Gajjar et al. 2022 searched 1,883 stars for negatively dispersed pulses, and the BLIPSS search used a fast folding algorithm on the Galactic Centre **[read]** ([Gajjar et al. 2022](https://arxiv.org/abs/2205.02964); [Suresh et al. 2023](https://arxiv.org/abs/2305.18527)). Two published discriminators are cheap to add to any pipeline that already dedisperses and folds. One is dispersion that is negative or otherwise not ν⁻²; the other is periodicity confined to a narrow band.

### What is not known

The genuinely open questions are astrophysical. They include the emission mechanism and nature of the isolated long-period transients, the cause of FRB activity windows, why no hyperactive repeater shows a stable spin period, and whether OJ 287's binary model survives the 2021–2022 tests **[search]** ([Komossa et al. 2023](https://arxiv.org/abs/2302.11646)). None of them is an unexplained signal waiting for decoding. For quasars, the defensible definition of "anomalous" sits above "periodic". It means coherence far beyond natural QPO behaviour, strictly achromatic or square-wave modulation, large variability faster than the light-crossing time in an unbeamed source, or significant symbol structure left after the stochastic and periodic parts are removed. Nothing of this kind has been reported (this ladder is a research inference built from the natural cases cited above).

## Detection is cheap and vetting is the product

### Radio narrowband search has known blind spots that a new tool can measure

The standard narrowband search runs a tree de-Doppler algorithm on spectrograms with about 3 Hz and 18 s resolution, at drift rates of ±2 to ±4 Hz/s and S/N thresholds of 10–25, then applies ON/OFF cadence filtering **[read]** ([Enriquez et al. 2017](https://arxiv.org/abs/1709.03491); [Price et al. 2020](https://arxiv.org/abs/1906.07750)). Its weaknesses are now quantified. A turboSETI-like process on standard BL products recovered only about **6%** of injected signals, against 94% for UCLA's pipeline, because above about 0.15 Hz/s a drifting signal smears across channels **[read]** ([Margot et al. 2023](https://arxiv.org/abs/2308.02712)). turboSETI 2.3.2 also never searches exactly zero drift and inflates S/N for injected signals **[read]** ([Choza et al. 2024](https://arxiv.org/abs/2312.03943)). The physically motivated drift range reaches 200 nHz, for example 200 Hz/s at 1 GHz, far beyond what archive searches have covered **[read]** ([Sheikh et al. 2019](https://arxiv.org/abs/1910.01148)). Over 10¹¹ trials per scan, a 10σ threshold implies essentially no thermal false alarms. The thresholds are set by human interference and the capacity to vet it, not by noise (computed during this research).

BLC1 is the defining lesson for cadence logic. It passed cadence filtering for about 2.5 hours and was still an intermodulation product of local interferers. Dozens of look-alikes sat at clock-harmonic frequencies, including some the pipeline had already discarded **[read]** ([Sheikh et al. 2021](https://arxiv.org/abs/2111.06350)). Sheikh et al. turned the episode into a ten-step verification checklist: check instruments, look for the signal in OFF scans at a lower threshold, consult the observatory's RFI catalogue, compare drift against human technology and against the target system, search the archive and the rest of the band for look-alikes, and re-observe with other instruments **[read]** ([Sheikh et al. 2021](https://arxiv.org/abs/2111.06350)). Its most transferable step is to search the rejected pile for look-alikes, because finding them is strong evidence of a systematic. A cheap built-in null test is to swap ON and OFF labels and count what passes.

### Anomaly searches outside radio fail on artefacts and source confusion

Unsupervised anomaly searches in time-domain surveys mostly surface systematics. Of 277 outliers that SNAD found in three ZTF DR3 fields, **68% were bogus**, mainly image-subtraction artefacts and asteroid overlaps, and the real finds were rare but known astrophysics **[read]** ([Malanchev et al. 2021](https://arxiv.org/abs/2012.01419)). Active learning (AAD/PineForest, Astronomaly) roughly doubles the yield of interesting objects per inspection compared with static scoring **[read]** ([Ishida et al. 2021](https://arxiv.org/abs/1909.13260); [Lochner & Bassett 2021](https://arxiv.org/abs/2010.11202)). That matters because human review budgets run to a few hundred objects.

The cross-archive failure mode is source confusion at the coarsest survey's resolution. Project Hephaistos's seven Dyson-sphere candidates were explained by background dusty galaxies in the WISE beam, and JWST confirmed this for two of them in July 2026 **[read]** ([Ren, Garrett & Siemion 2024](https://arxiv.org/abs/2405.14921); [Zackrisson et al. 2026](https://arxiv.org/abs/2607.09460)). The VASCO photographic-plate transients remain contested. A January 2026 analysis showed that their headline correlations depend on a uniform-random null that the plates violate, and that the nuclear-test correlation is "almost completely determined by the observation schedule" **[read]** ([Watters et al. 2026](https://arxiv.org/abs/2601.21946)). Two cheap checks follow. A blending check should compare the offset between the Gaia position and the infrared centroid and estimate the expected number of chance blends. A chromaticity check on dips works because opaque structures are grey and dust is not, which was the test that resolved Boyajian's Star **[read]** ([Boyajian et al. 2018](https://arxiv.org/abs/1801.00732)).

### The statistical policy has to be designed in, not bolted on

The methods literature converges on five requirements. Each detector needs false-alarm probabilities calibrated on empirical nulls, such as OFF scans, inverted or scrambled light curves, IAAFT surrogates (which preserve both the power spectrum and the amplitude distribution) and schedule-preserving permutations. The search needs explicit trials accounting. Completeness has to be measured by injection and recovery. Analysis choices have to be pre-registered. And error control has to stay valid as the search grows **[read]** ([Schreiber & Schmitz 2000](https://arxiv.org/abs/chao-dyn/9909037); [Thompson et al. 2018](https://arxiv.org/abs/1710.06758); [Gross & Vitells 2010](https://arxiv.org/abs/1005.1891)). For a tool that keeps adding archives, three controls fit. Online false-discovery-rate rules (LORD, SAFFRON) handle a growing stream of tests. E-values, combined with the e-BH procedure, handle dependent tests. Anytime-valid e-processes handle targets that are monitored repeatedly **[read]** ([Javanmard & Montanari](https://arxiv.org/abs/1502.06197); [Wang & Ramdas 2022](https://arxiv.org/abs/2009.02824); [Ramdas et al. 2023](https://arxiv.org/abs/2210.01948)). The first technosignature search found that uses false-discovery-rate control is the 2026 OVRO-LWA search **[read]** ([Kosogorov et al. 2026](https://arxiv.org/abs/2606.04304)). The scale arithmetic is stark. With 10⁹ light curves and 10³ effective frequencies, a global 3σ result needs a local significance of about 8σ, and that is only meaningful if the per-trial p-values are calibrated against red noise (computed during this research). For quasars, a Fourier triage stage followed by a Bayesian stage is the only published approach shown to scale to 10⁷ light curves, at about 40% true positives and 0.5% false positives **[search]** ([Banaszak et al. 2026](https://arxiv.org/abs/2601.15379)).

### Community protocols set the vocabulary and the disclosure rules

The International Academy of Astronautics (IAA) revised its Declaration of Principles for SETI in 2025–2026. The October 2025 draft asks for authentication by multiple facilities and organisations using different instruments. It also asks for prompt disclosure when a candidate is ruled out, clear labelling of speculation, and archiving of data, methods **and code** in at least two geographically separate repositories **[read]** ([Garrett et al. 2025](https://arxiv.org/abs/2510.14506)). Its ratification in 2026 is known from search summaries only **[search]** ([SETI Institute news](https://seti.org/news/beyond-disclosure-day/)). A 2026 paper quoting the update says that confirmation reports should record any detected content, and that a content-bearing signal turns the problem into one of "information stewardship" **[read]** ([Garrett 2026](https://arxiv.org/abs/2610.21645)). The Rio Scale 2.0 gives a numeric communication score. BLC1 scored R ≈ 0, and the scale offers no way to determine whether a signal is interference **[read]** ([Sheikh et al. 2021](https://arxiv.org/abs/2111.06350); [Forgan et al. 2019](https://doi.org/10.1017/s1473550418000162)).

Together these imply a tiered vocabulary for the tool. A "hit" crossed a threshold. A "flag" passed contaminant filters and the within-run false-discovery-rate control. A "signal of interest" passed the domain checklist. A "candidate" was re-detected in independent data. Each tier needs a public retraction path, and the tool should never apply the word "technosignature" to an unconfirmed result. Every null run should also be logged as covered "haystack" so that it becomes an upper limit. For scale, all large radio programmes to 2018 covered about 6×10⁻¹⁸ of the haystack **[read]** ([Wright, Kanodia & Lubar 2018](https://arxiv.org/abs/1809.07252)).

## Structure can be recovered without a key; meaning cannot

### The structural layer is mature engineering with known data requirements

The engineering for finding structure in an unknown signal is mature. At the physical layer, a power spectrum gives carrier and bandwidth, cyclostationary or power-law spectral lines give symbol rate and carrier, timing recovery and blind constant-modulus (CMA) equalisation follow, and clustering of the symbol cloud gives the alphabet size. Good open engines exist: GNU Radio (GPL-3.0) and liquid-dsp (MIT, release 1.8.3 in September 2026) **[read]** ([liquid-dsp](https://pypi.org/project/liquid-dsp/); [Godard 1980](https://doi.org/10.1109/TCOM.1980.1094608)). Automatic modulation classifiers, whether based on fourth-order cumulants or deep learning, pick only from closed lists of human modulations. They are hypothesis generators, not oracles **[read]** ([O'Shea, Roy & Clancy 2018](https://arxiv.org/abs/1712.04578)). One limit is decisive for design. Public BL fine-resolution products are total power sampled every ~18 s, so symbol and carrier analysis needs raw voltages, which are scarce in public archives.

For bitstreams, an algebraic toolbox tests each candidate parameter with a statistic that collapses when the parameter is right. Bit autocorrelation and folding find frame period and sync words. GF(2) rank deficiency and low-weight parity checks find block-code length. The Berlekamp–Massey algorithm finds the linear complexity of scramblers **[read]** ([Tixier 2015](https://arxiv.org/abs/1501.03715); [Massey 1969](https://doi.org/10.1109/TIT.1969.1054260)). All of these assume human-style linear codes. No maintained open library for blind code recognition was found, so Stargazer would implement these scans itself and confirm hypotheses with existing decoders.

Every designed message to date has hidden its layout in a factorisable length: Arecibo's 1,679 = 23×73 bits and Heller's 1,902,341 = 7×359×757. A 2026 re-analysis found that the raw algorithmic-complexity (BDM) minimum for Arecibo falls at the **wrong width (11)**. Width 23 emerges only after shape normalisation and calibration against shuffles (search-corrected p = 0.005), and the authors call this estimator sensitivity, "not a preregistered replication" **[read]** ([Zenil & Uthamacumaran 2026](https://arxiv.org/abs/2610.08861)). The A Sign in Space exercise showed the gap between layout and transform. A crowd extracted the bitmap in about 10 days, but the hidden reversible cellular-automaton layer took about a year to find **[search]** ([ESA](https://www.esa.int/ESA_Multimedia/Images/2024/10/Alien_signal_decoded)). Its raw SigMF recordings, about 4.5 GB per telescope under CC BY 4.0, are the best public known-answer test set **[read]** ([Zenodo 7982936](https://zenodo.org/records/7982936)).

Sample size sets hard limits. Block entropy of order n over an alphabet of size k needs N ≫ kⁿ symbols, so a 10⁴-point TESS light curve supports only orders of about 5–6. Ground-based survey cadence gives a Nyquist period of about 5–6 days and about 10³ samples per object per decade. Information-bearing structure is effectively testable only in radio voltages, photon event lists or similar high-rate data (computed during this research).

### Validation must simulate the whole search, not one statistic

The false-decode record shows how structure claims fail. A self-published 2026 preprint claimed an "algebraic quine" in the A Sign in Space payload at a chance probability of about 5×10⁻¹⁹, after an exhaustive search over finite fields, LFSRs and elliptic curves, with a "null" of 120 alternative inputs **[read]** ([Lacoche 2026](https://zenodo.org/records/19218629)). The Bible codes were refuted by showing that undisclosed researcher choices produce the same effect in other texts **[read]** for the paper's existence ([Bar-Hillel et al. 1999](https://doi.org/10.1214/ss/1009212243)). Kepler star KIC 5520878's "prime-number" lag correlations were traced by their own authors to two beating pulsation modes **[read]** ([Hippke et al. 2015](https://arxiv.org/abs/1409.1265)). A null p-value is valid only if the entire search pipeline is re-run on matched surrogates. On top of that, a credible claim needs agreement between methods from different families, held-out predictability and, where possible, a hard redundancy check such as a CRC pass, a syndrome check or exact reversibility. The quine author's own later, more cautious preprint concedes that "self-consistency is not external validation" **[read]** ([Zenodo 21032854](https://zenodo.org/records/21032854)).

A deeper limit is theoretical. An optimally compressed or encrypted message is indistinguishable from noise, and the most information-efficient electromagnetic format looks like black-body radiation. Structure tests can therefore catch only deliberately redundant, beacon-like signals **[read]** ([Lachmann, Newman & Moore](https://arxiv.org/abs/cond-mat/9907500)).

### Decipherment has always needed an anchor, and "language-like" statistics are not diagnostic

Every accepted decipherment rested on an external anchor: a bilingual text, a known related language, or names and numbers **[recalled]**, summarised as "the rarest category of achievement" **[read]** ([Luo, Cao & Barzilay 2019](https://arxiv.org/abs/1906.06718)). Computational decipherment reaches 60–93% accuracy only against known answers and with a related language supplied. Applied to undeciphered Iberian, the best model correctly declined to confirm Basque and produced no reading **[read]** ([Luo et al. 2021](https://arxiv.org/abs/2010.11054)). Two 2026 preprints show that the standard tests (Zipf slopes, conditional entropy and related measures) detect organisation without being specific to language. A meaning-only emblem system with no phonology, SIGIL, matched the Indus corpus on every scored criterion, and a decipherment stress test reached "high dictionary coverage" in English, Sanskrit and Tamil on the same corpus **[read]** ([Raghavendra 2026](https://arxiv.org/abs/2608.02999)). A Voynich-imitating cipher reproduces the manuscript's key statistics **[read]** ([Rozanova & Temerev 2026](https://arxiv.org/abs/2608.17096)).

Theory points the same way. Goldwasser et al. show that translation without parallel data is possible in principle only with a stated prior over plausible meanings, enough "common ground" and enough data. Their error falls with source complexity, and some ambiguities remain unresolvable **[read]** ([Goldwasser et al. 2023](https://arxiv.org/abs/2211.11081)). No non-human communication system had been translated by November 2026. Sperm-whale codas show combinatorial structure, but no coda has been assigned a meaning, and meaning claims elsewhere (elephant "names", marmoset labels) came from playback and behavioural grounding **[read]** ([Sharma et al. 2024](https://doi.org/10.1038/s41467-024-47221-8); [Oren et al. 2024](https://doi.org/10.1126/science.adp3757)).

Large language models learn an unseen language from a grammar book almost entirely through its parallel examples, not its explanations **[read]** ([Aycock et al. 2024](https://arxiv.org/abs/2409.19151)). They are good pattern completers and poor validators, and the 2026 AI "decipherment" of Linear A remains unrefereed and criticised as unverifiable **[search]** ([The Conversation, republished](https://www.downtoearth.org.in/science-technology/cracking-the-code-can-ai-help-us-decipher-ancient-languages)).

For Stargazer, the semantic layer should be a staged claim ladder: organisation, then segmentation, then symbol classes, then syntax-like dependencies, then anchored partial semantics. The anchors that qualify are counting sequences, arithmetic that holds across every instance, physical constants, rasters, and properties of the signal itself. Each reading must predict unseen parts of the message and report how many alternative conventions fit equally well. Non-mathematical interpretation should be labelled speculative and assigned to blind, independent teams, because Heller's challenge showed that spoilers destroy independence **[read]** ([Heller 2017](https://arxiv.org/abs/1706.00653)).

## Reuse the 2026 stack, and design around its fragility

### Prior art exists at hobby scale but without visible validation

No maintained, peer-reviewed, cross-archive technosignature miner exists. The nearest precedent is `seti-tools`, a single command-line tool with twelve "family" modules and a SQLite coverage database holding one row per run and per target. Its code is MIT and its papers and data are CC BY 4.0 **[search]** ([seti-tools](https://github.com/CharlesCNorton/seti-tools)). A 2025 paper shows how to run SETI searches through existing alert brokers **[search]** ([Gallay, Davenport & Croft 2025](https://arxiv.org/abs/2506.14744)). Several AI-assisted solo repositories appeared in 2025–2026, so Stargazer's novelty has to come from validation quality (null tests, injections, documented false-positive handling, a public coverage ledger), not from the number of archives it connects to. The volunteer-era projects carry one lesson. SETI@home's team said they "had not thought much" about vetting in the early years, and its Zooniverse successors stalled when the upstream team stopped preparing data, not for lack of volunteers **[search]** ([phys.org, Jan 2026](https://phys.org/news/2026-01-enthusiasts-home-scientists-homing.html); [Zooniverse project](https://www.zooniverse.org/projects/ucla-seti-group/are-we-alone-in-the-universe)).

### Reusable software is plentiful, but licences and radio-stack decay shape the choices

Almost every non-radio building block is a maintained package with a 2026 release. They cover archive access (astroquery, pyvo, lightkurve, LSDB/HATS), periodograms (astropy, nifty-ls), red-noise models (celerite2, tinygp, EzTao), X-ray timing (stingray), folding (riptide-ffa), outlier scoring (coniferest, PyOD, scikit-learn), complexity measures (antropy, ordpy, dit), matrix profiles (stumpy), change points (ruptures) and injection (setigen, LightCurveLynx) **[read]** ([PyPI lsdb](https://pypi.org/project/lsdb/); [PyPI riptide-ffa](https://pypi.org/project/riptide-ffa/); [PyPI coniferest](https://pypi.org/project/coniferest/); [PyPI eztao](https://pypi.org/project/eztao/)). Licences need deliberate handling. The fastest light-curve feature extractor, `light-curve`, declares GPL-3.0-or-later in its licence field while its classifier says MIT. GNU Radio 3, `your`, PRESTO, TOM Toolkit and healpy are copyleft **[read]** ([PyPI light-curve](https://pypi.org/project/light-curve/); [PyPI tomtoolkit](https://pypi.org/project/tomtoolkit/)). The choice is either a GPL-compatible licence for the whole project or GPL components behind plug-in interfaces with permissive fallbacks (an engineering reading of the licences, not legal advice). The machine-learning training sets have their own terms. RadioML is reported as non-commercial, CC BY-NC-SA **[search]** ([DeepSig](https://deepsig.squarespace.com/datasets-old)), and the Kaggle SETI set's licence was not verified.

The radio stack has decayed. The pip-installable CPU chain of blimpy, turboSETI and setigen still works with numpy 2.5 and Python 3.13, but turboSETI has had no release since May 2022, and blimpy's October 2026 fix is not on PyPI **[read]** ([PyPI turbo-seti](https://pypi.org/project/turbo-seti/); [PyPI blimpy](https://pypi.org/project/blimpy/)). The successors are hyperseti, which needs a CUDA GPU; seticore (C++/CUDA); and bliss, which is BSD-3, alpha and CPU-or-CUDA. None is on PyPI under its own name, and the PyPI package called `bliss` is an unrelated project **[read]** ([hyperseti README](https://raw.githubusercontent.com/UCBerkeleySETI/hyperseti/master/README.md); [seticore README](https://raw.githubusercontent.com/lacker/seticore/master/README.md)). BL's 2026 deep-learning pipeline, Aetherscan, needs NVIDIA GPUs and at least 288 GB of RAM **[read]** ([PyPI aetherscan](https://pypi.org/project/aetherscan/)). For pulsars and FRBs, sigpyproc 2.0, riptide and PINT form a permissively licensed CPU stack, all released in late 2026 **[read]** ([PyPI sigpyproc](https://pypi.org/project/sigpyproc/); [PyPI pint-pulsar](https://pypi.org/project/pint-pulsar/)).

### Volumes and compute favour subsets, cached inputs and co-located platforms

A benchmark run during this research timed turboSETI at about **8 seconds per coarse channel** on a 4-core CPU with synthetic data. That implies about 50 minutes per single-node ON/OFF cadence and about 7 hours per full L-band cadence. Downloads are the bottleneck, measured at about 27 MB/s from BL's cloud bucket. The public Voyager sample file cannot be searched at all, because it holds only two time integrations and blimpy needs at least three **[read]** ([PyPI turbo-seti](https://pypi.org/project/turbo-seti/)). NASA's Fornax platform gives 1,000 credits per user per year, a 200 GB home directory and compute next to the S3 data. It is limited to research and education and requires an account approved by its helpdesk **[read]** ([Fornax allotments](https://raw.githubusercontent.com/nasa-fornax/fornax-documentation/main/documentation/change-controlled-documents/user-resource-allotments-and-costs.md)). On this research's arithmetic, assuming one credit is about one US dollar, that allotment covers about 1–3 TB of working data for a year. Stargazer should therefore run identically off-platform on laptop-scale subsets of 10⁵–10⁷ objects, treat hosted platforms as an optimisation, and treat raw-radio re-processing as an opt-in mode for hand-picked pointings.

### Programme status is a design input, not background

Several services that Stargazer would depend on are at risk or changing. ZTF's confirmed operations end on 31 December 2026, with DR25 scheduled for 20 January 2027 **[search]** ([ZTF for astronomers](https://www.ztf.caltech.edu/ztf-for-astronomers.html)). Breakthrough Listen's ten-year, $100M commitment from July 2015 has run out, and no renewal announcement was found **[read]** for the commitment ([MacMahon 2026](https://arxiv.org/abs/2610.07482)) and **[search]** for its ending ([newspaceeconomy.ca](https://newspaceeconomy.ca/2026/10/09/what-does-breakthrough-listens-first-decade-show-about-scientific-data-infrastructure/)). Swift's science was suspended from February to August 2026, which leaves a data gap that a periodicity search must model **[search]** ([NASA Swift blog](https://science.nasa.gov/blogs/swift/2026/08/28/nasas-swift-restarts-science-observations/)). The OVRO 40 m blazar monitoring data are released by request only **[search]** ([OVRO 40 m data page](https://sites.astro.caltech.edu/ovroblazars/data.php)). There is churn as well: ANTARES's v1 API was retired, the `hipscat` package was renamed `hats`, Gaia's DataLink names changed, and astroquery is renaming parameters. All of this argues for thin, versioned connectors tested against recorded responses, pinned data-release versions, persistent caches, per-host rate limiters and plain file formats (Parquet, SQLite), so that a lapsed service or funder does not end the project.

## Conclusion

The research reverses the intuitive framing of the project. The scarce resource is not data or detection algorithms. It is credible negative knowledge: calibrated nulls, measured completeness, and a ledger of what was searched to what depth. The field's real advances in 2023–2026 are all of this kind. They include the 6% recovery figure for standard radio products, the 116-of-116 failed out-of-sample test for Gaia quasar periodicities, the JWST dismissal of the Hephaistos candidates, the wrong-width raw BDM result for Arecibo, and the SIGIL demonstration that "language-like" statistics are non-specific. A tool that produces calibrated null results and upper limits in a common currency would be more useful to the community than another candidate generator. It would also make any real anomaly more convincing when it appears.

The second implication concerns where effort pays off. The richest pattern-discovery surface for an open tool in 2027 will be Gaia DR4's epoch photometry and the stitched ZTF, Pan-STARRS and CRTS baselines of about 20 years, analysed against red-noise and scan-law nulls. Raw radio voltages, where information-bearing structure could in principle be tested, are largely closed to independent tools. The "translation" ambition is therefore best scoped as a structure engine. Validated on known-answer messages and natural controls, it would report organisation, layout and anchored mathematical self-description, and it would decline to assign meaning, just as the best decipherment model declined to read Iberian.
